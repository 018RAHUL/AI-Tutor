# AI Teacher — AI-Generated Visual Educational Tutor

> An AI Educational Video Generator + Interactive AI Teacher that explains concepts through synchronized visual storytelling, animated avatars, interactive simulations, and adaptive misconception remediation.

---

## 🌟 Overview & Philosophy

**AI Teacher** transforms topics or uploaded educational materials into a 2+ minute, scene-based, synchronized educational video.

- 👩‍🏫 **Living Animated Teacher Avatar**: Real-time eye blinking, facial expression states (`SPEAKING`, `EXPLAINING`, `QUESTIONING`, `LISTENING`, `THINKING`, `CORRECT`, `MISCONCEPTION`, `RE_EXPLAINING`), and phoneme-driven mouth animations.
- ⚡ **Subject-Aware Visual Engine**: Circuit simulations with moving electrons, water pipe analogies, mathematical derivations ($V = I \times R$), worked examples ($V = 12\text{V}, R = 4\Omega \implies I = 3\text{A}$), Binary Search algorithm traces, and quadratic graphs.
- 🎙️ **Synchronized Spoken Voice**: Spoken narration generated by Neural Edge-TTS with audio timing synchronization.
- 🧠 **LangGraph Orchestration & Real Parallelism**: Concurrent execution of Explanation, Visual, Examples, Questions, and Assessment agents with structured Fan-In scene planning.
- 🎯 **Interactive Question Pauses & Misconception Remediation**: Pauses for typed or voice responses (Web Speech STT), diagnoses underlying misconceptions (such as inverse vs direct proportionality confusion), and dynamically injects targeted remediation scenes.
- 📊 **Assessment & Learning Path**: Formative post-lesson quizzes, mastery scoring, and multi-session prerequisite roadmaps.
- 🔍 **Full Observability**: Live LangGraph execution trace drawer inspecting nodes, parallel timings, and model router decisions.

## 🚀 Quick Start

### 1. Requirements
- Python 3.10+
- Node.js 18+

### 2. Backend Setup
```bash
# Optional virtual environment
python -m pip install -r backend/requirements.txt
```

### 3. Run Application

#### Option A: Unified Full-Stack Server (FastAPI serving React)
```bash
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload
```
Open **`http://localhost:8000`** in your browser.

#### Option B: Vite Dev Server (Hot Module Reloading)
```bash
# Terminal 1: Backend
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload

# Terminal 2: Frontend
cd frontend
npm run dev
```
Open **`http://localhost:5173`** in your browser.
